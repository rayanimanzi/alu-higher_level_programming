# python-data_structures

This project covers Python data structures: lists, tuples, and basic
algorithms for manipulating them without relying on built-in shortcuts
like `pop()`, `max()`, or `str.replace()`.

## Tasks

0. Print a list of integers
1. Secure access to an element in a list
2. Replace element
3. Print a list of integers in reverse
4. Replace in a copy
5. Can you C me now?
6. Lists of lists = Matrix
7. Tuples addition
8. More returns!
9. Find the max
10. Only by 2
11. Delete at
12. Switch
