# python-more_data_structures

This project covers more advanced Python data structures: matrices,
sets, and dictionaries, along with functional tools like `map`, plus
a classic technical-interview exercise (Roman numeral conversion).

## Tasks

0. Squared simple
1. Search and replace
2. Unique addition
3. Present in both
4. Only differents
5. Number of keys
6. Print sorted dictionary
7. Update dictionary
8. Simple delete by key
9. Multiply by 2
10. Best score
11. Multiply by using map
12. Roman to Integer
